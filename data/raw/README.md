# Put the Kaggle file here (optional)

1. Download the **DataCo Smart Supply Chain** dataset from Kaggle (free account needed):
   https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis
2. Unzip it and copy **`DataCoSupplyChainDataset.csv`** into this folder.
3. Run `python src/main.py`. The pipeline detects the file and uses the real demand data.

The CSV (~90 MB) is ignored by git (see `.gitignore`), so it isn't uploaded to GitHub.
Delete or rename it to go back to the simulated dataset.
